# Movie Review Sentiment Analysis using RNN

## Project Overview

This project focuses on classifying movie reviews as Positive or Negative using Recurrent Neural Networks (RNN).

Technologies Used

- Python
- Deep Learning
- Recurrent Neural Network (RNN)
- TensorFlow / Keras
- Jupyter Notebook

Project Files

- "main.py" – Python application
- "simplernn.ipynb" – Model implementation notebook
- "simple_rnn_imdb.keras" – Trained RNN model
- "requirements.txt" – Required Python libraries

Objective

To analyze movie reviews and predict whether the sentiment expressed is positive or negative.
